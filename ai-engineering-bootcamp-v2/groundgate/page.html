The concept is real in the us-gaap taxonomy and spelled correctly. JPMorgan has never used it. That is decidable without a human and without a second model, which is the only reason this is worth anything.

What it checks

Did it look?

2

Does the source exist?

The cited identifier is absent from the system of record. This is the one nobody does.

3

Does the source say that?

The identifier is real and holds something else.

A claim this page used to make, and does not

The memorable version of this pitch is that a fabricated citation usually sits beside a correct figure — so anyone who checks the number finds it right and carries the fake source forward. An eight-question pilot showed exactly that: five invented concepts, four correct figures.

answers the model committed to11 of 40
cited a source that does not exist2 · 18%
gave the figure actually asked for1 · 9%
right figure beside an invented source0

At forty it is zero. The model that invents a source generally gets the number wrong too, and declines rather than committing most of the time. The hazard is real and it is why a fabricated citation matters — but this measurement did not observe it, so the page says so instead of quietly restating the number.

Using it

from groundgate import Gate, Run

gate = Gate(source=my_invoice_system)
v = gate.check(Run(answer=reply, tool_calls=recorded_calls))

v.outcome          # "pass" | "flag" | "block"
v.citation_exists  # is the source it named real?
print(v)           # BLOCK: cited `INV-00000`, which is not in the source

A Source needs one method — exists(id). An invoice table, a ticket system, a document store, a filer’s XBRL facts.

What it will not claim

A verified source is not a verified answer.

All three checks can pass on an answer that cites a real invoice, quotes it correctly, and answers a question you did not ask.

Fabrication depends on how the question is put.

Two earlier runs with the figure left in the question found 1 fabrication in 25 and 1 in 40 — the model could decline and be entirely right, and did so 24 times out of 25. Quote the condition with the number.

18% is one run of forty at temperature zero.

The shape is the finding; the figure is indicative. A different sample gives a different number.

“Did it look?” flags, it does not block.

An answer that consulted nothing may still be right. It must not be credited, though: nine of fifty runs in the parent project made no tool call, all nine answered with the commonest correct label, and all nine scored as hits.
